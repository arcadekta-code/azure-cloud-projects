# Architecture

This folder contains the architecture and deployment design of the **ABC Technologies - Enterprise Azure Infrastructure Deployment** project.

## Planned Architecture Components

- Azure Resource Group
- Azure Virtual Network (VNet)
- Subnet
- Network Security Group (NSG)
- Public IP Address
- Windows Server Virtual Machine
- IIS Web Server
- Azure Monitor
- Activity Log
