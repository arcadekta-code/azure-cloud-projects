# Step 03 - Create Subnet

## Objective

Create a subnet inside the Virtual Network for hosting the Windows Virtual Machine.

---

## Azure Portal Navigation

Home → Virtual Networks → vnet-abctech-prod-malaysiawest-01 → Subnets → Add

---

## Configuration

- Virtual Network: vnet-abctech-prod-malaysiawest-01
- Subnet Name: snet-web
- Address Range: Default Azure subnet range

---

## Why Subnet?

A subnet divides a Virtual Network into smaller logical networks.

Benefits:

- Better network organization
- Security isolation
- Easy workload separation
- Supports Network Security Groups (NSG)

---

## Result

Subnet created successfully and used for deploying the Windows Virtual Machine.
